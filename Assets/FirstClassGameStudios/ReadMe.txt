Idle Clicker Business Tycoon Simulation v1.2
--------------------------------------------


UPDATE 1.2 - JULY 31st, 2017

- The engine has been updated to allow alternate store prefabs. This means stores can have alternate looks or function. To demonstrate a new alternate store prefab has been added with different colors. The 2nd store in savedata_update.xml uses an alternate prefab.
- To prevent writing over someones saved game savedata.xml was remaned to savedata_update.xml. If there is no gamefile available then the engine will use savedata_update.xml.
- Enabled the simple tip rotator by default
- Cleaned up a variety of warnings related to variables not being used and some ambigious references

1. Installation

There are no special requirements for installation. You should be able to open the example scene 'main' and play the game directly in the editor.

You can edit the game values in the GameData file in the data folder.
